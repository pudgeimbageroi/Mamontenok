## Шаг 1 — Регион Vercel (это чинит курс)

Главная причина «не подтягивается курс»: АТБ пускает только российские и европейские IP.
На **Hobby-плане** строка `export const preferredRegion` в коде **игнорируется** — регион задаётся в настройках проекта.

1. Vercel → твой проект → **Settings**
2. Слева **Functions**
3. **Function Region** → выбери **Frankfurt, Germany (fra1)**
4. Save
5. Вкладка **Deployments** → у последнего деплоя «…» → **Redeploy**

Без пункта 5 настройка не применится — регион зашивается в момент сборки.

Проверил из своей песочницы: API отвечает нормально, CNY buying = 13.06, ЦБ = 12.88. Значит с самим АТБ всё в порядке, дело только в IP.

Если после Франкфурта всё равно не тянет — новая версия покажет в интерфейсе жёлтую плашку с точным регионом выполнения и подсказкой. Курсы при этом можно вписать руками, расчёт не встанет.

## Шаг 2 — SQL в Supabase

```sql
-- ─── Курс АТБ на ИП ───
alter table public.rates
  add column if not exists atb_ip_rate numeric(10, 4);

-- ─── Новый список каналов ───
update public.deals set channel = 'atb' where channel = 'rshb';

alter table public.deals drop constraint if exists deals_channel_check;
alter table public.deals add constraint deals_channel_check
  check (channel in ('atb', 'atb_ip', 'shage'));

update public.deals set moex_ticker = null where moex_ticker is not null;
alter table public.deals drop constraint if exists deals_moex_ticker_check;

update public.cashflow set channel = 'atb' where channel = 'rshb';

alter table public.cashflow drop constraint if exists cashflow_channel_check;
alter table public.cashflow add constraint cashflow_channel_check
  check (channel in ('atb', 'atb_ip', 'shage'));

-- ─── Фиксируем режим «свой курс» ───
-- Если стоял процент от ЦБ — пересчитываем в конкретный курс,
-- чтобы цена для студента не прыгнула после деплоя.
update public.markup_settings ms
set
  custom_rate_value = case
    when ms.mode = 'percent' then coalesce(
      (select r.cbr_rate from public.rates r
        where r.cbr_rate is not null
        order by r.fetched_at desc limit 1) * (1 + ms.percent_value / 100),
      ms.custom_rate_value
    )
    else ms.custom_rate_value
  end,
  mode = 'custom_rate';
```

# Что изменилось

## Калькулятор
- **Убрана наценка %** — блок с двумя карточками («Наценка %» / «Свой курс») заменён одним крупным полем «Мой курс для студента». Ставишь число, сохраняется автоматически.
- **Убрана Биржа РСХБ** целиком — и канал, и подтяжка MOEX, и настройки брокера.
- **Появился АТБ · ИП** — третья карточка. Курс вводится вручную, премия +0.03 к нему **не** применяется (в отличие от физлица).
- Три канала: `АТБ · физлицо` (синий) · `АТБ · ИП` (зелёный) · `沙哥` (розовый).
- При ошибке API — жёлтая плашка с причиной и напоминанием что курсы можно вписать руками.

## Везде остальное
- **Сделка**: три кнопки канала, лейбл поля курса меняется («Курс АТБ ИП»).
- **Список сделок**: фильтр по каналу обновлён, метки в строках новые.
- **Касса**: две карточки счетов — «АТБ (физлицо)» и «АТБ (ИП)», плюс розовая строка 沙哥.

## Фикс потери курсов
Раньше при нажатии «Обновить» вручную вписанные курсы (ИП, 沙哥) затирались — новая запись в `rates` создавалась без них. Теперь переносятся из предыдущей записи.
