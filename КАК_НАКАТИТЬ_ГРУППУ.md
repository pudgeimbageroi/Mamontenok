# Уведомления в группу + фикс курса

Проверено: `tsc --noEmit` чисто, `next build` собирается.
Никакой SQL-миграции не требуется.

## Часть 1 — Уведомления в общую группу

### Шаг 1. Залей файлы (7 штук)

```
НОВЫЙ:     app/api/rates/cbr/route.ts        ← курс ЦБ в обход блокировки

Заменить:  lib/notifications.ts              шлёт в группу + хелперы форматирования
           app/api/deals/route.ts            подробное уведомление о новой сделке
           app/api/deals/[id]/route.ts       НОВОЕ: уведы на правку и удаление
           app/api/cashflow/route.ts         добавлен счёт и способ в текст
           app/api/telegram/webhook/route.ts /chatid, /atb, /ip, /sha, /my
           app/app/calc/calc-client.tsx      кнопка тянет ЦБ + АТБ
```

Push → дождись деплоя.

### Шаг 2. Узнай ID группы

1. Добавь бота в вашу с Егором группу (если ещё не добавлен — он там уже есть по твоим словам)
2. Напиши в группе: **`/chatid`**
3. Бот ответит числом вида `-1001234567890` — скопируй его

Если бот молчит в группе — у него включён Privacy Mode. Лечится так:
@BotFather → `/mybots` → твой бот → Bot Settings → Group Privacy → **Turn off**.
Потом убери бота из группы и добавь заново.

### Шаг 3. Пропиши переменную в Vercel

Settings → Environment Variables → Add:

```
TELEGRAM_GROUP_CHAT_ID = -1001234567890
```

→ Save → **Deployments → Redeploy** (без редеплоя переменная не подхватится).

### Что теперь падает в группу

| Событие | Что в сообщении |
|---|---|
| ⚡ Новая сделка | студент, универ, назначение, сумма ¥, канал, сколько платит, прибыль, доля на каждого |
| ✅ Сделка закрыта | студент, сумма, переход статуса, прибыль |
| 🔄 Смена статуса | было → стало |
| ✏️ Сделка изменена | что именно поменялось (сумма / курс / канал) и как это сдвинуло прибыль |
| 🗑 Сделка удалена | кто удалил и какая была прибыль |
| 💸 Движение в кассе | категория, сумма, счёт, способ, комментарий |

Внизу каждого — кто это сделал.

Логика адресатов: в группу летит **всегда**, в личку — только партнёру, который этого не делал. Так инициатор не получает дубль.

## Часть 2 — Почему курс не обновляется

Проверил из своей песочницы напрямую: **АТБ отвечает нормально** (CNY buying 13.06). Проверил и через Node-овский fetch, тем же кодом что в приложении — тоже 200 OK.

Значит дело не в коде, не в заголовках и не в TLS. Забанен именно IP-диапазон Vercel — причём и Франкфурт тоже, судя по твоему скриншоту. Vercel сидит на AWS, а банки часто режут облачные подсети целиком, чтобы отсечь парсеры.

Из кода это не чинится. Что сделано вместо этого:

**ЦБ теперь тянется автоматически** — новый endpoint берёт курс с `cbr-xml-daily.ru`, с фолбэком на официальный `cbr.ru/scripts/XML_daily.asp`. Оба проверил, отдают 12.8849, кодировка windows-1251 разбирается корректно. Эти источники не блокируют облака.

**Курс АТБ вписывается за 5 секунд с телефона** — новые команды бота:

```
/atb 13.06   курс АТБ (физлицо)
/ip 13.0     курс АТБ на ИП
/sha 13.3    курс 沙哥
/my 13.5     мой курс для студента
```

После любой из них бот присылает карточку с пересчитанной маржой — сразу видно, что получилось.

**Кнопка «Обновить» больше не всё-или-ничего** — сначала ЦБ, потом АТБ. Если банк не дался, ЦБ всё равно обновится, а плашка честно скажет что делать дальше.

### Если хочешь именно автоматику

Единственный надёжный путь — свой прокси на IP, который АТБ пускает: дешёвый российский VPS (~200 ₽/мес) с крошечным сервисом, который ходит в АТБ и отдаёт ответ приложению. Скажи — напишу и сервис, и инструкцию по развёртыванию.

Но честно: курс АТБ меняется раз-два в день, а `/atb 13.06` в телеге занимает пять секунд. Прокси имеет смысл, только если захочется обновлять курс по расписанию без твоего участия.
